# SuperMarket_Bill System
This is the console based code in A simple supermarket billing application built with Python, featuring customer details, item management, discounts, CGST/SGST calculation, payment processing, and bill generation.

Supermarket Billing System

Smart Mart Supermarket Billing System is a simple and user-friendly billing application designed to manage supermarket transactions efficiently. The project is built using Python and provides features for entering customer and cashier details, adding multiple products, calculating item totals, applying discounts, calculating CGST and SGST, processing Cash/UPI payments, calculating change, and generating a complete bill summary.

The project is designed as a beginner-friendly Object-Oriented Programming (OOP) project and demonstrates the practical use of Python classes, objects, constructors, methods, lists, calculations, and user input.

Key Features
🏪 Supermarket and GST details
👤 Customer and cashier information
🛒 Multiple item entry
🔢 Quantity and price calculation
💰 Automatic total amount calculation
🎁 Discount calculation
🧾 CGST and SGST calculation
💳 Cash and UPI payment options
💵 Automatic change calculation
📋 Detailed bill summary
💾 Clean and structured Python OOP implementation
🌐 Can be extended with an HTML, CSS, and JavaScript GUI

Technologies: Python • OOP • HTML • CSS • JavaScript

Purpose: A practical mini-project for learning Python programming, Object-Oriented Programming, billing logic.
